Create or update an OpenCode skill using `$ARGUMENTS` as the initial brief.

Workflow:
1. Review existing skills and avoid duplicating capabilities.
2. Define when it triggers, what it solves, and which references it needs.
3. Prefer concrete, reusable skills.
4. Edit the necessary files and summarize how it is invoked and when it adds value.
