Create or update an OpenCode agent using `$ARGUMENTS` as the initial brief.

Workflow:
1. Review `agents/` and `opencode.jsonc` first.
2. Define the agent's exact job, mode, permissions, and model.
3. Ask only the questions needed to avoid a generic agent.
4. If something similar already exists, reuse it or converge it.
5. Edit the final file and summarize why it exists and when to use it.
